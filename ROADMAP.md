# SlowAI Roadmap

This roadmap is a proposal, not a delivery commitment.

## Phase 0 — Open foundation
- [x] Draft mission and manifesto
- [x] Draft contribution guidance and Claude Code instructions
- [x] Select and add Apache License 2.0 (maintainer approved)
- [ ] Audit existing content for publication rights, dependencies and company-specific terminology
- [ ] Adopt a code of conduct and issue/PR templates

## Phase 1 — Establish a reproducible baseline
- [ ] Inventory current synthetic industrial benchmark and tests
- [ ] Define evaluation dimensions: outcome quality, cost, latency, compute and energy where measurable
- [ ] Add a clearly documented non-AI baseline
- [ ] Separate measured data from simulated outputs

## Phase 2 — Minimum sufficient AI
- [ ] Compare deterministic rules, lightweight classifiers, small models and frontier models on the same tasks
- [ ] Publish escalation criteria and failure cases
- [ ] Report sensitivity to workloads and quality thresholds

## Phase 3 — Responsible impact assessment
- [ ] Document system boundaries and data collection methods
- [ ] Add privacy, safety, accessibility and human-oversight checks
- [ ] Explore energy and lifecycle impact measurement without unsupported claims

## Phase 4 — Community
- [ ] Publish reusable benchmark templates and contribution examples
- [ ] Invite independent replication and critical review
- [ ] Expand beyond industrial scenarios when suitable open data exists
