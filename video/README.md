# SlowAI story video

`scene-v3.html` is the current 92-second video. It renders frame by frame in a browser and is encoded with ffmpeg:

```bash
python -m http.server 8765 &                     # from the repository root
npm install --no-save playwright@1.58.2 && npx playwright install chromium
node video/render.mjs slowai-story-v3.mp4        # needs ffmpeg on PATH
```

## What is real, simulated or illustrative

| Element | Kind |
| --- | --- |
| Photographs in `images/` | AI-generated illustrations (see below), labelled on every frame |
| The 100 MW-class campus incident and every count in the router and the final pyramid | Reproducible simulation: `story/data/campus-v1.json`, generated by `python -m story.generator.campus` (seed 20261011) |
| "Escalation fixed 11 answers" | Measured in the simulation: escalated cases compared with what the simulated racks actually did |
| Drip-tray leak probability (0.94) | Simulated model output; no vision model was trained |
| Frontier model | Not run |

The campus scale follows public AI factory reference designs (100 MW campuses, liquid-cooled racks around 130–150 kW). No energy, cost or CO₂ figure appears in the video.

## Image provenance

The ten images in `images/` were generated on 11 October 2026 by the maintainer with ChatGPT image generation, from the prompts in the project's "SlowAI video v3" document (photorealistic, no text, no logos, no brand names). They are illustrations, not photographs of a real facility. `scene.html` is the earlier v2 video and is kept for reference.
